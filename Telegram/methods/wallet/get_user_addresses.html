GetUserAddressesRequest

Both users and bots may be able to use this request. See code examples.

---functions---
wallet.getUserAddresses#5275dfdd flags:# force:flags.0?true id:Vector<InputUser> addresses:Vector<string> = wallet.UserAddresses

Returns

wallet.UserAddresses

This type can only be an instance of:

UserAddresses

Parameters

idInputUserAnything entity-like will work if the library can find its Input version (e.g., usernames, Peer, User or Channel objects, etc.). A list must be supplied.
addressesstringA list must be supplied.
forceflagThis argument defaults to None and can be omitted.

Known RPC errors

This request can't cause any RPC error as far as we know.

Example

from telethon.sync import TelegramClient
from telethon import functions, types

with TelegramClient(name, api_id, api_hash) as client:
    result = client(functions.wallet.GetUserAddressesRequest(
        id=['username'],
        addresses=['some string here'],
        force=True
    ))
    print(result.stringify())
