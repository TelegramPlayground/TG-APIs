SetCardStickersRequest

Both users and bots may be able to use this request. See code examples.

---functions---
wallet.setCardStickers#068509ac flags:# stickers:Vector<InputWalletCardSticker> bg_nft_address:flags.0?string = wallet.Card

Returns

wallet.Card

This type can only be an instance of:

Card

Parameters

stickersInputWalletCardStickerA list must be supplied.
bg_nft_addressstringThis argument defaults to None and can be omitted.

Known RPC errors

This request can't cause any RPC error as far as we know.

Example

from telethon.sync import TelegramClient
from telethon import functions, types

with TelegramClient(name, api_id, api_hash) as client:
    result = client(functions.wallet.SetCardStickersRequest(
        stickers=[types.InputWalletCardSticker(
            coordinates=types.MediaAreaCoordinates(
                x=7.13,
                y=7.13,
                w=7.13,
                h=7.13,
                rotation=7.13,
                radius=7.13
            ),
            nft_address='some string here'
        )],
        bg_nft_address='some string here'
    ))
    print(result.stringify())
