EnableBackupRequest

Both users and bots may be able to use this request. See code examples.

---functions---
wallet.enableBackup#4500c525 flags:# parts:Vector<bytes> new_public_key:flags.1?bytes proof:flags.2?WalletOwnershipProof = WalletState

Returns

WalletState

This type can be an instance of either:

WalletStateWalletStateEmpty

Parameters

partsbytesA list must be supplied.
new_public_keybytesThis argument defaults to None and can be omitted.
proofWalletOwnershipProofThis argument defaults to None and can be omitted.

Known RPC errors

This request can't cause any RPC error as far as we know.

Example

from telethon.sync import TelegramClient
from telethon import functions, types

with TelegramClient(name, api_id, api_hash) as client:
    result = client(functions.wallet.EnableBackupRequest(
        parts=[b'arbitrary\x7f data \xfa here'],
        new_public_key=b'arbitrary\x7f data \xfa here',
        proof=types.WalletOwnershipProof(
            timestamp=42,
            signature=b'arbitrary\x7f data \xfa here'
        )
    ))
    print(result.stringify())
